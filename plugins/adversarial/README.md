# Adversarial

Connects your agent to [Adversarial Risk Management](https://adversarial.com) through its MCP server, `https://api.adversarial.com/mcp`. Find and score risks against your organization's methodology, log and triage incidents, link risks and incidents, open or link Jira, Linear and ServiceNow tickets, and review compliance policy changes.

## Requirements

An active account in a verified Adversarial organization. Each user signs in with their own Adversarial account in the browser the first time the server connects, and every action runs with that user's permissions. [Sign up](https://app.adversarial.com) or [contact us](https://adversarial.com/contact).

## Skills

| Skill | Use it to |
| --- | --- |
| `onboarding` | Confirm the connected organization and permissions, and see how it classifies risks and incidents |
| `register-analysis` | Count, break down and report on risks and incidents |
| `risk-intake` | Turn a finding or scan result into a scored risk, or rescore one |
| `incident-triage` | Log incidents, set severity against your response plan, and keep status current |
| `tickets` | Open, link or unlink Jira, Linear and ServiceNow tickets on risks and incidents |
| `policy-gap-analysis` | Compare a policy with your approved compliance documents and propose changes |
